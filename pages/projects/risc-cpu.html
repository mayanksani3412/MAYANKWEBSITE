Project 01 / RTL & Verification

8-bit RISC-style CPU.

A processor project described in my existing portfolio and associated with the 45-day CSIR-CEERI training certificate. The block diagram below is illustrative, not a screenshot of the RTL or a verified execution trace.

Overview

Processor blocks, brought together.

The recorded project is an 8-bit RISC-style CPU designed using SystemVerilog. The documented blocks include an ALU, register file, control unit, program counter, instruction memory, and data memory.

The source portfolio describes module integration, testbench-based behavioral simulation, and waveform analysis in Xilinx Vivado.
