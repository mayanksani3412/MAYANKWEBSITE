Project 04 / Public repository

A reusable N-bit adder.

A Verilog implementation of a 5-bit full adder using structural modeling and a generate block, with a testbench and simulation waveform files documented in the repository.

Open GitHub repository ↗

Design

Ripple carry, parameterized.

The repository documents a one-bit full-adder module composed into an N-bit ripple-carry adder through a generate loop.

  • Structural Verilog modules
  • Parameterized adder
  • Functional testbench
  • Example operands and expected sum/carry documented in README
  • Verilog HDL
  • Vivado / Icarus Verilog
  • GTKWave
