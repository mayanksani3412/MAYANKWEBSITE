Neon Highway 2D racing game.

A browser-based arcade racing game built with HTML5, CSS, and vanilla JavaScript, as described in its public project README.

Open GitHub repository ↗Visit listed live demo ↗

Documented features

Arcade gameplay for desktop and mobile.

  • Player-controlled car and animated multi-lane highway
  • Random traffic, collision detection, and coin collection
  • Score, speed, and personal-best tracking
  • Pause, resume, game-over, and restart interactions
  • Keyboard and touch controls
